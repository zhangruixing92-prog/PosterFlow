# PosterFlow

运营素材自动批量适配工具 — 基于**主视觉海报**的多尺寸商业化生成。

## 项目目标

### 一句话定位

**把一张主视觉海报，自动适配成多种运营尺寸素材，保持品牌风格一致，并批量导出。**

### 核心目标

1. **一图多尺寸** — 上传一张主海报（如 1080×1920），批量生成竖版、横版、方版、Banner 等运营规格，减少手工改图。
2. **风格一致** — 适配时保持主海报的调性、色彩、光影、材质、留白和信息层级；不随意新增或改写文字、Logo、产品、人物。
3. **元素可控** — 用户在主图上框选要保留的元素，系统只把这些内容放进各尺寸成图，避免裁切人物、乱丢文案。
4. **智能适配，本地兜底** — AI 排版（Qwen-VL）决定元素位置，AI 扩图（万相）只延展纯装饰/背景区；失败时回退本地规则合成。
5. **批量交付** — 勾选尺寸 → 一键生成 → ZIP 打包下载。
6. **可精调** — 每个尺寸可单独查看/修改模型、输入图、提示词，并单独重新生成。

### 产品原则

- **本地先处理尺寸**：裁切、装饰区提取在本地完成，模型只做「适配」，不做「拆切逻辑」。
- **背景与元素分离**：扩图只用装饰区；元素在合成阶段贴 **一次**，避免重影。
- **同类尺寸共用策略**：竖版 → 方版 → 横版 分批生成；跨类自动去掉主视觉，避免裁切人物。
- **输出是最终成图**：不是对比图，不是原图与裁切图叠加。

### 明确非目标（当前版本）

- 不是通用 PS/设计工具，不做自由画布编辑。
- 不自动生成或改写文案内容。
- 无 AI Key 时走本地规则，效果与 AI 模式有差异。
- SAM 自动分割、模版 JSON 导入等为后续扩展，尚未落地。
